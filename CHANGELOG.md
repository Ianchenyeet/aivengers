# Changelog

All notable changes to **AIvengers** are documented in this file.

## [1.0.0] - 2026-11-18
### Initial Marketplace Release
- **AIvengers Secondary Side Bar Tab:** Dedicated VS Code multi-agent workspace collaboration view with automatic local agent discovery, per-slot model selection, live `vscode.lm` model querying, custom prompt templates, and saved session history drawer.
- **Multi-Role Registry, RYB Color Mixing & Two-Tab Slot Picker:** Supports 23 roles across 6 categories with bidirectional conflict detection, Gossett & Chen subtractive RYB paint-color mixing on dynamic slot borders, curated team presets, split-from-front slot creation (`+`), and flexible 0+ roles per slot.
- **Same-Provider Multi-Model Teams & Model-Name Reporting:** Supports running distinct models from the same provider side by side while displaying each teammate's Model Name and mixed role color in headers, logs, and feed cards.
- **Same-Session Continuity, File Attachments & Signal-Only Feed:** Reuses open chat sessions across follow-up prompts (`Message 1`, `Message 2`, ... in `USER_INBOX.md`), supports file/folder attachments, interactive plan approval polls, task locks, and automatic sign-off (`[SIGN-OFF]` + `final_summary`).
- **Interactive Quick Guide & Setup Instructions (`?`):** Includes in-panel setup guidance, official local extension usage notes, and one-click workspace hub initialization (`AIvengers: Initialize Drop-In AIvengers Hub Folder in Workspace`).
