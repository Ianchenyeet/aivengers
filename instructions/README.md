# 📖 User Instructions & Detailed Specifications

This directory holds deep-dive feature specifications, architecture diagrams, user design briefs, API schemas, and reference materials.

### How to use this folder:
1. **For the User:**
   - When you have a detailed prompt, spec, or multi-step feature requirement that is too long for `USER_INBOX.md`, create a markdown file here (e.g. `instructions/prompt_enhancer_spec.md`).
   - Mention the file path in `USER_INBOX.md` under **Current Focus**.

2. **For AI Agents:**
   - Read the relevant spec files in this directory before planning tasks or writing code.
   - Maintain documentation integrity: do not delete or overwrite specifications unless explicitly requested by the user.
